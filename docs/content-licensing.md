# Content licensing and provenance

The application code is AGPL-3.0-or-later. That code license does not silently
relicense imported dictionaries, examples, or media.

The seven bundled modules contain 105 entries generated as original demonstration
content for this repository (15 per module). Their manifests identify source,
coverage `demo`, non-official status, checksum, and CC0-1.0. Overlap produces fewer
fused learning identities than raw pack entries by design. Examples are short and
original; module names describe product entry points and do not imply an examination
board's endorsement or complete official list.

The 20 local SVG scenes are original geometric illustrations. Each record in
`apps/desktop/public/assets/scenes/assets.json` includes asset ID, file, author,
license (CC0-1.0), and purpose. Validation rejects remote URLs, scripts,
`foreignObject`, unexpected paths, and excessive size. No hotlinked image is used.

Users must provide a source name and license/use-right statement for imports. The
application preserves that report locally but cannot determine whether the user
actually holds rights. Export does not grant additional redistribution permission.

Future provider or AI output must carry provenance and an “unverified” state until
a user confirms it; it may supplement but never overwrite pack facts. No such
provider is implemented in v0.1.
