# 60-second demonstration

0–10s: Start with the welcome screen. Point out “offline first,” no account, and
the six-step progress indicator.

10–20s: Continue to module selection. Toggle CET-6 alongside Senior/CET-4 and explain
that one shared sense becomes one learning object while homographs remain separate.

20–30s: Complete attention budget, quiet hours, corner, and motion settings; skip or
undo the local placement demo.

30–40s: Reveal the first Compact card, open “Why now?”, choose a four-way feedback
rating, and note the independently labelled scaffold direction.

40–48s: Close the card. Show that it becomes a Dot with a snooze deadline and no
record was deleted. Reopen and expand to the dashboard.

48–56s: Show module coverage, five mastery levels, attention budget, confusion graph,
and cue fingerprint. Open a word detail to show memberships, examples, note, and
two-step deletion.

56–60s: Open Settings. Point to CSV/JSON dry-run import, export-all, system voice,
motion-off, privacy controls, and two-step delete-all.
