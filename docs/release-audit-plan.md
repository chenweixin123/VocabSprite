# Release audit plan

Date: 2026-08-18. Scope: VocabSprite v0.1 working tree.

1. Re-read root instructions, README/docs, architecture, learning, packs, privacy,
   threat model, accessibility, and Git status.
2. Install from the lock file and inventory Node, pnpm, Rust, MSVC, WebView2.
3. Run format, lint, typecheck, Vitest, pack/schema/checksum, SVG, benchmark, web
   build, Playwright, Rust fmt/clippy/test, and Windows Tauri bundle.
4. Review stable identity/fusion/unsubscribe/upgrade conflicts and construct same-
   spelling/different-sense cases.
5. Review FSRS UTC/retention/rating integration, deterministic queue, budgets, snooze,
   scaffold directions, rescue, confusion caps/decay, and deletion.
6. Review SQLite migration/idempotence/indexes/transactions/cascades/backup boundary.
7. Review CSP, capabilities, external links, shell/network absence, clipboard gate,
   autostart, tray, no-focus show, position clamping, import size/path/HTML/checksum.
8. Run 10k/100k performance fixture and record actual results/bundle sizes.
9. Generate screenshots and inspect onboarding, Compact, Dot, Expanded, settings,
   reduced motion, missing voice/image, high contrast, and keyboard journeys.
10. Fix every P0/P1 and feasible P2, rerun affected/full suites, then write an honest
    release recommendation with remaining manual/platform blockers.
